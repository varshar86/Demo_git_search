About the project Searchify:
	Followed clean architecture
	Mediator pattern (used MediatR library)
	JWT Authentication
	MS SQLite Server
	Xunit testing framework

Project Structure:
	Core
	    SearchDemo.Domain 
            SearchDemo.Application
	Infrastructure
  	    SearchDemo.Infrastructure
	Presentation
	    SearchDemo.API
	Test 
	    SearchDemo.Test

LOCAL RUNTIME NOTE
------------------
The application uses SQLite for local/demo execution. The database is created automatically
under Searchify\Data\searchify.db. This avoids requiring a machine-specific SQL Server
instance during evaluation. The solution also contains a solution-local Directory.Build.props
that disables the .NET workload resolver because this Web API does not use MAUI/iOS/MacCatalyst.
